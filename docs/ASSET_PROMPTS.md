## Hindi narration (not image prompts)

Spoken audio is **not** recorded by a human kathāvāchak. `scripts/tts.py` calls [Sarvam Bulbul v3](https://docs.sarvam.ai/api-reference-docs/text-to-speech/convert) with speaker `priya`, `language_code=hi-IN`, `pace=0.9`, `temperature=1.0` (API max). Each `listenHi` sentence is synthesized separately, concatenated with a short silence, and timed in `art/audio/{eventId}.cues.json` so cinema subtitles match the ear.

Source text lives in `data/events.json` → `listenHi`. Without `SARVAM_API_KEY`, the script falls back to Microsoft Edge TTS voice `hi-IN-SwaraNeural`.
